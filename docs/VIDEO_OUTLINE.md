## Before recording

- `pnpm db:up` → `pnpm db:migrate && pnpm db:seed` (fresh seed = clean demo data), then `pnpm dev:real`.
- Pre-open tabs: README, SYSTEM_DESIGN diagrams, ai-log, one agent brief, Swagger `/docs`, `/metrics`, the web app.
- Rehearse the conflict step: have the cURL from `docs/curl-examples.md` ready.
- Check the clock: same-day slots exist only before ~15:00 dealership time unless you pin `CLOCK_OVERRIDE`.
- **Grafana take** (record separately, splice in at step 7): the Docker stack wants the same ports as `pnpm db:up` /
  `pnpm dev:real` (:54329, :3000, :5173), so stop those first. Then `docker compose --profile app --profile obs up -d --build`,
  `pnpm loadtest:seed`, start `DURATION=60s pnpm loadtest:run`, open http://localhost:3001 after ~20 s (the panels need a
  few 5 s scrapes). Afterwards run the invariant query from [`loadtest/README.md`](../loadtest/README.md) on camera.
